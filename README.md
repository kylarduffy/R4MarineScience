# Module 1: R4MarineScience

This contains the workshop exercises and practical activities completed as part of the R4MarineScience Module. The workshops focus on developing practical skills in R programming, data management, statistical analysis and visualisation with applications to marine and ecological datasets.

## Repository Contents

Each workshop includes R scripts and/or Quarto documents (.qmd) demonstrating the application of programming and data analysis techniques. The repository also contains:
- supporting datasets
- summary tables
- figures
- rendered HTML reports

## Workshop Overview

Workshop 1: Foundations of Data Science
Introduction to R programming, data cleaning, statistical summaries and visualisation using the Palmer Penguins dataset.

Workshop 2: Extracting Ecological Signals
Advanced data wrangling, integration of multiple datasets and investigation of fish abundance along an estuarine salinity gradient.

Workshop 3: Extracting Ecological Signals
Scientific figure reconstruction, fisheries data analysis and visualisation using Queensland Shark Control Program data.

## Skills and Learning Objectives

Throughout these workshops, I am developing skills in:
- Data wrangling and cleaning
- Data visualisation
- Statistical analysis
- Reproducible research
- Marine science applications
